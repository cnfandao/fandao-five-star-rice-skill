## 这个 SKILL 能帮你做什么

### 查合作餐厅 — 找到你身边米饭好吃的餐厅

第一期开放：**广州、深圳、南京**（更多城市陆续开放）

问一句"广州有哪些餐厅用饭导的米？"，就能查到按米其林、黑珍珠、必吃榜、饭导星选分类的合作餐厅。

**这些餐厅的米饭，差评就找饭导赔。**

### 28天鲜磨米 — 大米也有最佳赏味期

大米和咖啡一样，磨完就开始"走味"。常温下第28天是口感下降的拐点。饭导的供应链周转平均3-5天，给到餐厅的米基本不超过10-15天生产日期。饭导承诺所有产品到消费者手上一定是28天以内的。

### 煮饭技巧 — 来自五星好评米饭大师的实战经验

米水比例怎么调？煮饭要不要放油？为什么不能用热水煮饭？电饭煲怎么选？五星好评米饭大师都能解答。
